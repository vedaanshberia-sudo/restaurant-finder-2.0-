
# NearBites India

NearBites India helps people discover nearby cafes, restaurants, and food spots based on their preferences.

## Features

- Cafe-first discovery, with restaurants included
- City and state selection within India
- Optional device location
- Food, cuisine, budget, vibe, and distance preferences
- Recommendations designed to include lesser-known places
- OpenStreetMap-based location search

## Technology

- HTML, CSS, and JavaScript
- Netlify Functions
- OpenStreetMap and Nominatim
- Overpass API

## Deployment

1. Connect this GitHub repository to Netlify.
2. Set the publish directory to `.`.
3. Set the functions directory to `netlify/functions`.
4. Deploy the site.

The included `netlify.toml` configures these paths.

## Data and limitations

OpenStreetMap data is available under the Open Database License (ODbL).
Provide appropriate attribution to OpenStreetMap contributors.

Public geocoding and map-data services have usage policies and rate limits.
Coverage and address accuracy may vary.

Restaurant ratings and food quality cannot be guaranteed from map data alone.
Any additional datasets must be reviewed for licensing, attribution, accuracy,
and permission to redistribute their contents.

NearBites India is an independent discovery project and is not affiliated
with Swiggy or Zomato.
